# Dublin Pubs - The Impossible Dream

Myself and my brother have a goal to drink in every pub in Dublin. The site keeps our visits and reviews alongside the current Revenue licence list.

## Site

[Dublin Pubs Map](https://irishshagua.github.io/dublin-pubs-map)

The map shows Done visits, unlinked OpenStreetMap pub candidates, or both. Some visit links are automatic estimates, and unlinked candidates may already have been visited. OSM bars are used to match visits but are not added to Undone. Search the candidate list or select orange markers, then choose up to nine stops on desktop or three in a mobile browser and open a Google Maps walking route starting and ending at home. The home address stays in the browser until directions are opened and can be cleared on the page. Done popups show visit IDs; candidate popups and list rows link to their OSM IDs for fixing overlaps.

The site reads `visits.json`, `osm-pubs.json` and the Revenue licence snapshot from `master`. See the main branch README for the match checklist and data refresh workflow. OpenStreetMap data is credited to its contributors and available under the [ODbL](https://www.openstreetmap.org/copyright).

The template used for the site is from [StartBootstrap](https://github.com/BlackrockDigital/startbootstrap-stylish-portfolio).
